# ENSC 351 Assignment 2: Light Dip Detector

`light_sampler` runs on the BeagleY-AI. It samples a light sensor through the
ADC, counts dips in light level each second, flashes an LED emitter with PWM at
a frequency set by the rotary encoder, and answers commands over UDP port 12345.

## Structure

- `hal/`: low-level hardware access modules (include as `"hal/xxx.h"`)
- `app/`: application modules and `main.c`
- `build/`: generated by CMake; delete to clean

## Building

```shell
cmake -S . -B build          # configure (add -DENABLE_ASAN=OFF to disable the address sanitizer)
cmake --build build          # build; copies light_sampler to ~/ensc351/public/myApps/
```

Select the cross-compiler kit in VS Code (CMake: Select a Kit) to build for the target.

## Address sanitizer

ASan is on by default (`ENABLE_ASAN`). Turn it off for sampling-rate tests and
before running valgrind; the target needs `libasan` installed to run an ASan build.

## Testing UDP

```shell
netcat -u 192.168.7.2 12345
```
